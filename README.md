# HALLAYM Pay
Private multi-project gateway. Configure Render secrets MONGODB_URI, ADMIN_TOKEN (random >=32 chars), HAMYON_SHOP_ID, HAMYON_SHOP_KEY and PUBLIC_URL (HTTPS, no trailing slash). Do not commit secrets. Set Hamyon callback paths /api/hamyon/prepare and /api/hamyon/complete only after migration of existing outstanding payments. Verify provider terms and real low-value payment before production. API uses per-project Bearer keys, unique order IDs and server-side status validation. Amount includes a 1–999 UZS matching offset, disclosed via base_amount and amount. Provider timeouts require manual review; never blindly retry. This initial release uses status polling, not outgoing webhooks. Render free instances can sleep; use always-on hosting for production. Run npm install && npm test. No cardholder credentials are collected.
